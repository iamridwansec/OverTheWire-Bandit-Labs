# Bandit Level 26 → Level 27

## Objective

Learn how to navigate a Linux environment after obtaining shell access and locate protected resources.

## Concepts Learned

* Interactive shell
* Shell navigation
* File permissions
* User privileges

## Key Command

### `ls`

Lists the files and directories within the current location. It is one of the most fundamental Linux commands for exploring the filesystem after gaining shell access.

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |
| `cat`   | Displays the contents of a text file.  |

## Key Takeaway

Obtaining shell access is only the beginning. Being able to navigate the filesystem and understand permissions is essential for working effectively on Linux systems and forms a core skill in cybersecurity.

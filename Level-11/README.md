# Bandit Level 10 → Level 11

## Objective

Learn how to identify and decode Base64-encoded data in Linux.

## Concepts Learned

* Base64 encoding
* Data encoding and decoding
* Text transformation

## Key Command

### `base64`

Encodes binary or text data into Base64 format and decodes Base64-encoded data back to its original form. It is commonly used for data transmission, email attachments, and configuration files.

## Commands Introduced

| Command  | Purpose                               |
| -------- | ------------------------------------- |
| `base64` | Encodes or decodes Base64 data.       |
| `cat`    | Displays the contents of a text file. |

## Key Takeaway

Base64 is an **encoding** method, not an encryption technique. Understanding the difference between encoding and encryption is an essential concept in cybersecurity and data handling.

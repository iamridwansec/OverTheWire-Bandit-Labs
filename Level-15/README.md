# Bandit Level 14 → Level 15

## Objective

Learn how to communicate with network services running on specific ports within a Linux system.

## Concepts Learned

* Localhost
* TCP ports
* Client-server communication
* Network services

## Key Command

### `nc` (Netcat)

A versatile networking utility used to establish TCP/UDP connections, test network services, transfer data, and troubleshoot connectivity. It is often referred to as the "Swiss Army knife" of networking.

## Commands Introduced

| Command | Purpose                                          |
| ------- | ------------------------------------------------ |
| `nc`    | Connects to and interacts with TCP/UDP services. |
| `ssh`   | Establishes a secure remote connection.          |
| `cat`   | Displays the contents of a text file.            |

## Key Takeaway

Many applications communicate through network ports, even on the same machine. Understanding how to connect to and interact with network services is a foundational skill in networking, Linux administration, and cybersecurity.

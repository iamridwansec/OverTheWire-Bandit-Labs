# Bandit Level 21 → Level 22

## Objective

Learn how scheduled tasks are managed in Linux and how to inspect cron jobs.

## Concepts Learned

* Cron jobs
* Task scheduling
* System automation
* Configuration files

## Key Command

### `cron`

Cron is the Linux service responsible for executing commands or scripts automatically at scheduled intervals. Cron job configurations are commonly stored in directories such as `/etc/cron.d/`.

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `cat`   | Displays the contents of a text file.  |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |

## Key Takeaway

Cron is a powerful automation tool used to schedule repetitive tasks such as backups, maintenance, and monitoring. Understanding how to inspect cron configurations is an important skill for Linux administration, incident response, and cybersecurity.

# Bandit Level 32 → Level 33

## Objective

Learn how to analyze and escape from a restricted shell environment to gain access to a standard Linux shell.

## Concepts Learned

* Restricted shells
* Shell escaping
* Command execution
* Linux environments

## Key Command

### `$0`

`$0` is a special shell variable that represents the name of the current shell or script. Understanding special shell variables is useful when working with shell environments, scripting, and troubleshooting.

## Commands Introduced

| Command  | Purpose                                        |
| -------- | ---------------------------------------------- |
| `$0`     | Refers to the current shell or script name.    |
| `echo`   | Displays text or the value of shell variables. |
| `whoami` | Displays the current user.                     |
| `pwd`    | Prints the current working directory.          |

## Key Takeaway

Restricted shells are designed to limit user actions, but understanding how shells behave and how special shell variables work is an important part of Linux administration and cybersecurity. Analyzing shell environments is a valuable skill when troubleshooting or working in constrained systems.

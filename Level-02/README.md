# Bandit Level 1 → Level 2

## Objective

Understand how Linux handles filenames that begin with special characters and learn how to safely work with them from the terminal.

## Concepts Learned

* Special characters in filenames
* Command-line argument interpretation
* Referencing files safely

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |
| `cat`   | Displays the contents of a file.       |
| `file`  | Identifies the type of a file.         |
| `du`    | Displays disk usage information.       |
| `find`  | Searches for files and directories.    |

## Key Takeaway

Linux treats some characters as having special meaning in the shell. Knowing how the shell interprets filenames is essential for working safely and efficiently with files in the terminal.

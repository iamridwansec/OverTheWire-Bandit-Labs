# Bandit Level 0 → Level 1

## Objective

Learn how to navigate the Linux filesystem and inspect files using basic command-line utilities.

## Concepts Learned

* Home directory
* Listing files
* Changing directories
* Reading file contents
* File identification

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |
| `cat`   | Displays the contents of a file.       |
| `file`  | Identifies the type of a file.         |
| `du`    | Displays disk usage information.       |
| `find`  | Searches for files and directories.    |

## Key Takeaway

This level introduces the essential Linux commands used to navigate the filesystem and inspect files. Mastering these basics is important because nearly every future Bandit challenge builds upon them.

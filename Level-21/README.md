# Bandit Level 20 → Level 21

## Objective

Learn how local network services communicate over TCP and how to test client-server interactions.

## Concepts Learned

* TCP communication
* Localhost networking
* Network daemons
* Client-server model
* SetUID programs

## Key Command

### `nc` (Netcat)

Creates TCP or UDP connections, listens on ports, and transfers data between systems. It is widely used for testing network services, debugging connections, and simulating client-server communication.

## Commands Introduced

| Command      | Purpose                                      |
| ------------ | -------------------------------------------- |
| `nc`         | Creates or listens for TCP/UDP connections.  |
| `./<binary>` | Executes a program in the current directory. |
| `ls -l`      | Displays file permissions and ownership.     |

## Key Takeaway

Understanding how applications communicate over localhost is a fundamental networking skill. Tools like `nc` make it easy to test and troubleshoot client-server communication, which is essential in Linux administration and cybersecurity.

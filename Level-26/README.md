# Bandit Level 25 → Level 26

## Objective

Learn how Linux user shells are configured and how to inspect and interact with alternative shell environments.

## Concepts Learned

* Login shells
* User account configuration
* Shell escape
* Pager programs

## Key Command

### `cat`

Displays the contents of text files. It is commonly used to inspect system configuration files, including those that define user login shells and account settings.

## Commands Introduced

| Command | Purpose                                                 |
| ------- | ------------------------------------------------------- |
| `cat`   | Displays the contents of a text file.                   |
| `more`  | Displays text one screen at a time.                     |
| `ssh`   | Connects securely to a remote system.                   |
| `vi`    | Opens the Vim text editor for viewing or editing files. |

## Key Takeaway

Not every Linux user logs in with a traditional shell like Bash. Understanding alternative shells and terminal-based programs, as well as how to navigate or exit them, is an important skill for Linux administration, troubleshooting, and cybersecurity.

# Bandit Level 2 → Level 3

## Objective

Learn how to work with filenames that contain spaces in the Linux command line.

## Concepts Learned

* Filenames with spaces
* Shell parsing
* Escaping and quoting filenames

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |
| `cat`   | Displays the contents of a file.       |
| `file`  | Identifies the type of a file.         |
| `du`    | Displays disk usage information.       |
| `find`  | Searches for files and directories.    |

## Key Takeaway

Spaces are treated as separators by the shell. Understanding how to reference filenames containing spaces is a fundamental Linux skill that applies to everyday system administration and scripting.

# Bandit Level 29 → Level 30

## Objective

Learn how to inspect and work with branches in a Git repository.

## Concepts Learned

* Git branches
* Branch management
* Repository navigation
* Version control workflows

## Key Command

### `git branch`

Lists, creates, or manages branches in a Git repository. Branches allow developers to work on different features or versions of a project independently.

## Commands Introduced

| Command        | Purpose                                                 |
| -------------- | ------------------------------------------------------- |
| `git clone`    | Downloads a remote Git repository to the local machine. |
| `git branch`   | Lists and manages repository branches.                  |
| `git checkout` | Switches between branches.                              |
| `git status`   | Displays the current state of the repository.           |

## Key Takeaway

Branches are a core feature of Git that enable parallel development and experimentation. Knowing how to inspect and switch between branches is essential for software development, collaboration, and security assessments.

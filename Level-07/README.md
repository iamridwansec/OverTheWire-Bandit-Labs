# Bandit Level 6 → Level 7

## Objective

Learn how to search the Linux filesystem using file ownership and size as search criteria.

## Concepts Learned

* File ownership
* User and group permissions
* System-wide file searching
* File attributes

## Key Command

### `find`

Searches for files and directories using criteria such as ownership, permissions, size, name, and location. It is commonly used by system administrators to locate specific files across a system.

## Commands Introduced

| Command | Purpose                                                         |
| ------- | --------------------------------------------------------------- |
| `find`  | Searches for files and directories based on specified criteria. |
| `cat`   | Displays the contents of a text file.                           |
| `ls`    | Lists files and directories.                                    |

## Key Takeaway

Linux files have ownership information that can be used as part of a search. Understanding users, groups, and file attributes is an important skill for Linux administration and cybersecurity.

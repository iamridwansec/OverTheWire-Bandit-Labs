# Bandit Level 31 → Level 32

## Objective

Learn how to modify, commit, and push changes to a remote Git repository.

## Concepts Learned

* Git staging
* Commits
* Remote repositories
* Version control workflow

## Key Command

### `git push`

Uploads local commits to a remote Git repository, allowing changes to be shared or submitted. It is the final step in the standard Git workflow after staging and committing changes.

## Commands Introduced

| Command      | Purpose                                         |
| ------------ | ----------------------------------------------- |
| `git add`    | Stages changes for the next commit.             |
| `git commit` | Records staged changes in the local repository. |
| `git push`   | Uploads local commits to a remote repository.   |
| `git status` | Displays the current state of the repository.   |

## Key Takeaway

A typical Git workflow involves staging changes, creating a commit, and pushing it to a remote repository. Mastering this workflow is essential for software development, collaboration, and maintaining version-controlled projects.

# Bandit Level 22 → Level 23

## Objective

Learn how to inspect and understand shell scripts used by automated system tasks.

## Concepts Learned

* Shell scripting
* Cron jobs
* Script analysis
* Linux automation

## Key Command

### `cat`

Displays the contents of a text file. It is commonly used to inspect shell scripts, configuration files, and other text-based resources to understand how they work.

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `cat`   | Displays the contents of a text file.  |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |
| `sh`    | Executes a shell script.               |

## Key Takeaway

Reading and understanding shell scripts is a valuable Linux skill. Many system administration and cybersecurity tasks involve analyzing scripts to determine their behavior, troubleshoot issues, or understand automated processes.

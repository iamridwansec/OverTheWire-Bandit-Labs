# Bandit Level 5 → Level 6

## Objective

Learn how to search for files in Linux based on specific properties such as size, type, and permissions.

## Concepts Learned

* File searching
* File attributes
* File permissions
* Human-readable files

## Key Command

### `find`

Searches for files and directories based on specified criteria, such as name, size, type, permissions, or location. It is one of the most powerful file management tools available in Linux.

## Commands Introduced

| Command | Purpose                                                     |
| ------- | ----------------------------------------------------------- |
| `find`  | Searches for files and directories based on given criteria. |
| `file`  | Identifies the type of a file.                              |
| `cat`   | Displays the contents of a text file.                       |
| `ls`    | Lists files and directories.                                |
| `cd`    | Changes the current working directory.                      |

## Key Takeaway

Searching for files using their attributes is more efficient than manually browsing directories. Mastering the `find` command is an essential skill for Linux system administration, troubleshooting, and cybersecurity.

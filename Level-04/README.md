# Bandit Level 3 → Level 4

## Objective

Learn how to identify and work with hidden files and directories in Linux.

## Concepts Learned

* Hidden files
* Directory navigation
* Viewing hidden directory contents

## Commands Introduced

| Command | Purpose                                |
| ------- | -------------------------------------- |
| `ls`    | Lists files and directories.           |
| `cd`    | Changes the current working directory. |
| `cat`   | Displays the contents of a file.       |

## Key Takeaway

Hidden files are commonly used in Linux to store configuration and system-related data. Knowing how to locate and inspect them is an essential skill for Linux administration and cybersecurity.

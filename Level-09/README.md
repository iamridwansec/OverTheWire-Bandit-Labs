# Bandit Level 8 → Level 9

## Objective

Learn how to identify unique lines within a text file using Linux text-processing utilities.

## Concepts Learned

* Text processing
* Sorting data
* Identifying duplicate and unique entries
* Command pipelines

## Key Command

### `sort` and `uniq`

* `sort` arranges lines of text in a specific order.
* `uniq` filters duplicate lines from sorted input, making it useful for identifying unique or repeated entries.

## Commands Introduced

| Command | Purpose                                                      |
| ------- | ------------------------------------------------------------ |
| `sort`  | Sorts lines of text alphabetically or numerically.           |
| `uniq`  | Filters or reports repeated and unique lines in sorted data. |
| `cat`   | Displays the contents of a text file.                        |

## Key Takeaway

Linux provides powerful text-processing tools that can be combined to analyze data efficiently. Understanding how commands like `sort` and `uniq` work together is a valuable skill for log analysis, scripting, and cybersecurity tasks.

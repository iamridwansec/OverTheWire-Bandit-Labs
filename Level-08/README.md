# Bandit Level 7 → Level 8

## Objective

Learn how to search for specific text within a file using Linux command-line tools.

## Concepts Learned

* Text searching
* Pattern matching
* File content analysis

## Key Command

### `grep`

Searches for text that matches a specified pattern within one or more files. It is widely used to filter logs, configuration files, and command output.

## Commands Introduced

| Command | Purpose                                         |
| ------- | ----------------------------------------------- |
| `grep`  | Searches for text matching a specified pattern. |
| `cat`   | Displays the contents of a text file.           |
| `less`  | Views large text files one page at a time.      |

## Key Takeaway

Efficiently searching through file contents is a fundamental Linux skill. The `grep` command is one of the most frequently used tools for locating information quickly in text files and command output.

# Bandit Level 9 → Level 10

## Objective

Learn how to extract readable text from files containing binary or non-printable data.

## Concepts Learned

* Binary files
* Human-readable strings
* Text extraction
* Pattern searching

## Key Command

### `strings`

Extracts printable, human-readable text from binary files. It is commonly used during file analysis, reverse engineering, and digital forensics to inspect executable files and other binary data.

## Commands Introduced

| Command   | Purpose                                         |
| --------- | ----------------------------------------------- |
| `strings` | Extracts printable text from binary files.      |
| `grep`    | Searches for text matching a specified pattern. |
| `cat`     | Displays the contents of a text file.           |

## Key Takeaway

Not all files are plain text. Learning how to extract readable information from binary data is an important skill in Linux, cybersecurity, malware analysis, and digital forensics.

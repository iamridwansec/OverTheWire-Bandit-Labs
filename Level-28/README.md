# Bandit Level 27 → Level 28

## Objective

Learn how to clone and inspect a remote Git repository from a local machine.

## Concepts Learned

* Git repositories
* Repository cloning
* Remote repositories
* Version control

## Key Command

### `git clone`

Creates a local copy of a remote Git repository. This allows you to inspect files, track changes, and work with a project's complete version history.

## Commands Introduced

| Command     | Purpose                                                 |
| ----------- | ------------------------------------------------------- |
| `git clone` | Downloads a remote Git repository to the local machine. |
| `cd`        | Changes the current working directory.                  |
| `ls`        | Lists files and directories.                            |
| `cat`       | Displays the contents of a text file.                   |

## Key Takeaway

Git is the most widely used version control system in software development and cybersecurity. Knowing how to clone and explore remote repositories is an essential skill for source code analysis, collaboration, and security research.

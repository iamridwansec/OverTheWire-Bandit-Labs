# Bandit Level 11 → Level 12

## Objective

Learn how to transform text using character substitution techniques in Linux.

## Concepts Learned

* ROT13 cipher
* Character substitution
* Text transformation
* Simple ciphers

## Key Command

### `tr`

Translates or replaces characters from one set to another. It is commonly used for text transformation, character replacement, and data manipulation in shell pipelines.

## Commands Introduced

| Command | Purpose                                    |
| ------- | ------------------------------------------ |
| `tr`    | Translates or replaces characters in text. |
| `cat`   | Displays the contents of a text file.      |

## Key Takeaway

ROT13 is a simple substitution cipher that rotates alphabetic characters by 13 positions. Understanding basic text transformation techniques is useful when working with encoded or obfuscated data in Linux and cybersecurity.

# Bandit Level 23 → Level 24

## Objective

Learn how to create and execute a basic shell script that interacts with automated system tasks.

## Concepts Learned

* Shell scripting
* Script execution
* Cron jobs
* File permissions
* Linux automation

## Key Command

### `chmod`

Changes the permissions of a file or directory. It is commonly used to make shell scripts executable before they can be run by the operating system or other programs.

## Commands Introduced

| Command | Purpose                                           |
| ------- | ------------------------------------------------- |
| `chmod` | Modifies file permissions.                        |
| `touch` | Creates a new empty file.                         |
| `cat`   | Displays or writes file contents.                 |
| `sh`    | Executes a shell script.                          |
| `ls -l` | Displays detailed file permissions and ownership. |

## Key Takeaway

Writing your first shell script is an important milestone in learning Linux. Shell scripts automate repetitive tasks and form the foundation of system administration, DevOps, and many cybersecurity workflows.

# Bandit Level 13 → Level 14

## Objective

Learn how to authenticate to a remote system using an SSH private key instead of a password.

## Concepts Learned

* SSH key authentication
* Private keys
* Public key cryptography
* Secure remote access

## Key Command

### `ssh`

Establishes a secure connection to a remote system. SSH supports multiple authentication methods, including passwords and cryptographic key pairs.

## Commands Introduced

| Command | Purpose                                     |
| ------- | ------------------------------------------- |
| `ssh`   | Connects securely to a remote system.       |
| `ls`    | Lists files and directories.                |
| `cat`   | Displays the contents of a text file.       |
| `chmod` | Changes file permissions to control access. |

## Key Takeaway

SSH key-based authentication is more secure than password-based authentication and is widely used for administering Linux servers. Understanding how to use private keys is a fundamental skill for system administrators and cybersecurity professionals.

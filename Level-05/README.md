# Bandit Level 4 → Level 5

## Objective

Learn how to identify file types and distinguish human-readable files from other file formats.

## Concepts Learned

* File types
* Human-readable vs. binary files
* File inspection

## Key Command

### `file`

Determines the type of a file by examining its contents rather than relying on its filename or extension. This command is useful for identifying text files, executables, images, archives, and other file formats.

## Commands Introduced

| Command | Purpose                                                 |
| ------- | ------------------------------------------------------- |
| `ls`    | Lists files and directories.                            |
| `cd`    | Changes the current working directory.                  |
| `file`  | Identifies the type of a file.                          |
| `cat`   | Displays the contents of a text file.                   |
| `reset` | Restores the terminal if the display becomes corrupted. |

## Key Takeaway

Understanding file types is an essential Linux skill. Before opening an unknown file, it is good practice to identify its type to avoid unexpected behavior and work with it appropriately.

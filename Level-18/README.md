# Bandit Level 17 → Level 18

## Objective

Learn how to compare files and identify differences between their contents.

## Concepts Learned

* File comparison
* Text differences
* Change detection
* File integrity

## Key Command

### `diff`

Compares two files line by line and highlights the differences between them. It is commonly used to track changes in source code, configuration files, and text documents.

## Commands Introduced

| Command | Purpose                                            |
| ------- | -------------------------------------------------- |
| `diff`  | Compares two files and displays their differences. |
| `cat`   | Displays the contents of a text file.              |
| `less`  | Views large text files one page at a time.         |

## Key Takeaway

Comparing files is a fundamental Linux skill for identifying modifications, verifying file integrity, and tracking changes. Tools like `diff` are widely used in software development, system administration, and cybersecurity.

# Bandit Level 28 → Level 29

## Objective

Learn how to inspect a Git repository and analyze its commit history.

## Concepts Learned

* Git commits
* Version history
* Repository inspection
* Source code tracking

## Key Command

### `git log`

Displays the commit history of a Git repository, including commit IDs, authors, dates, and messages. It is an essential command for understanding how a project has evolved over time.

## Commands Introduced

| Command      | Purpose                                                 |
| ------------ | ------------------------------------------------------- |
| `git clone`  | Downloads a remote Git repository to the local machine. |
| `git log`    | Displays the commit history of a repository.            |
| `git show`   | Shows details of a specific commit.                     |
| `git status` | Displays the current state of the repository.           |

## Key Takeaway

Git preserves every committed change in a project's history. Understanding how to inspect commit history is a valuable skill for auditing code, investigating changes, and performing security reviews.

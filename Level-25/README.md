# Bandit Level 24 → Level 25

## Objective

Learn how to automate repetitive network interactions and understand the concept of brute-force testing.

## Concepts Learned

* Brute-force techniques
* Automation
* TCP communication
* Shell scripting
* Client-server interaction

## Key Command

### `nc` (Netcat)

A versatile networking utility used to communicate with TCP/UDP services. It can send and receive data, making it useful for testing network applications and automating interactions with network services.

## Commands Introduced

| Command | Purpose                                                      |
| ------- | ------------------------------------------------------------ |
| `nc`    | Connects to and communicates with TCP/UDP services.          |
| `for`   | Repeats a set of commands in a shell loop.                   |
| `echo`  | Prints text or variables to the terminal or another command. |
| `cat`   | Displays the contents of a text file.                        |

## Key Takeaway

Automating repetitive tasks is a core Linux skill. Shell loops combined with networking tools allow efficient interaction with services, while this level introduces the concept of brute-force testing in a controlled learning environment.

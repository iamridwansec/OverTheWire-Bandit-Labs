# Bandit Level 30 → Level 31

## Objective

Learn how to inspect Git tags and understand their role in version control.

## Concepts Learned

* Git tags
* Repository metadata
* Version tracking
* Release management

## Key Command

### `git tag`

Lists, creates, and manages tags in a Git repository. Tags are commonly used to mark important commits, such as software releases or milestones.

## Commands Introduced

| Command      | Purpose                                                 |
| ------------ | ------------------------------------------------------- |
| `git clone`  | Downloads a remote Git repository to the local machine. |
| `git tag`    | Lists and manages repository tags.                      |
| `git show`   | Displays information about a specific tag or commit.    |
| `git status` | Displays the current state of the repository.           |

## Key Takeaway

Git tags provide a convenient way to identify significant points in a project's history. Understanding how to inspect and use tags is an important skill for version control, software releases, and repository analysis.
